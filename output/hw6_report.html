How it compares to the Problem 2 estimate

The handbook alone was estimated at $0.0010/call uncached and $0.0001/call cached (via tiktoken). Real calls ran 2.2–3.7× higher in absolute terms — expected, since a real call also carries the instructions, tool schemas, and (per Problem 6's finding) pays for the shared prefix across two internal model calls per run. The ratio held up almost exactly: a cached call still costs about 1/10th of a full-price one.

§ 03

What the defenses cost

Three layers — code (sanitize + extract before the model sees anything), design (approval-gated tools + an independent decision verifier), prompt (explicit rules about trusting extracted facts over later claims). Measured per doc, steady-state:

Code layer

−6 to +75 tok

Stripping hidden content nets negative on docs that had any; redacting a sentence + adding extracted fields nets positive. Average +28 tokens/doc (~$0.0000028).

Prompt layer

+428 tok / call

Fixed cost of prompt.md's defense rules section, sent every call. Shares the handbook's cache block, so after the first call it costs ~$0.0000043 — nearly free.

Design layer

$0.00

Approval gating and the Python-side verifier add no tokens at all. Cost is $0 unless a trap tool is actually attempted — then one extra round-trip (~$0.0004) to confirm the denial.

§ 05

Recommendation to the store manager

Yes — turn it on for real vendor mail, with one condition kept in place.

Keep send_email and approve_payment gated behind a human's sign-off. The agent reads and recommends; it should never be the one hitting "send" or "pay," and right now it structurally can't be — every attempt is logged and requires approval. That's the one thing this report would ask you not to turn off.

Projected cost at 1,000 docs/day for 30 days: ~$11.50/month in model API calls (defended, cache warm)
  • Accuracy: 12/12 on the practice set and 10/10 on the exam set, both checked against the handbook's own data.
  • Security: every attack tried against it — 3 from the practice set, 2 written specifically to find new gaps — is now caught, and none ever got a real email sent or payment approved, in any configuration tested.
  • Cost: the defenses are effectively free (+$0.0000006/doc); caching the handbook is what actually matters, and it's already cutting the real bill by 86.7%.
  • One known limitation: the redaction filter is pattern-based and can flag a legitimate correction email (seen once, harmlessly, in testing) — worth a periodic spot-check of the audit trail, not a blocker to turning it on.
